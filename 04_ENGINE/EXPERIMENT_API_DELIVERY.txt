================================================================================
SECURITY FEATURES
================================================================================

Layer 1: Syntax Validation
  - Python AST parsing (detects malformed code)
  - Require execute_strategy(context) function
  - Reject before sandbox execution

Layer 2: Sandbox Rule Enforcement
  - Banned Modules: os, sys, subprocess, socket, urllib, importlib, threading
  - Banned Calls: eval, exec, compile, open, __import__
  - Banned Attributes: os.*, sys.*, socket.*, place_order()
  - Pattern Detection: Live order attempts, file I/O

Layer 3: Execution Isolation
  - Subprocess sandboxing (separate process, no parent access)
  - 5-minute timeout with automatic process kill
  - Memory limits: 512MB per experiment
  - CPU limits: 80% max utilization
  - Restricted builtins: No dangerous functions

Layer 4: Guardian Integration
  - Gate 4: Execution integrity verification (time bounds, resources)
  - Gate 5: Canary execution on subset of data
  - Authority=ZERO: Immutable audit trail, non-negotiable
  - Correlation IDs: Full end-to-end tracing

QUICK START
================================================================================

1. Start API Server:
   $ cd /path/to/04_ENGINE
   $ python -m uvicorn experiment_api:app --host 0.0.0.0 --port 8001

2. Submit Strategy:
   $ curl -X POST http://localhost:8001/experiment/submit \
     -H "Content-Type: application/json" \
     -d '{"name":"Test","strategy_code":"def execute_strategy(context):\n    return {\"action\":\"hold\"}","priority":"normal"}'

3. Check Status:
   $ curl http://localhost:8001/experiment/{experiment_id}/status

4. Get Results:
   $ curl http://localhost:8001/experiment/{experiment_id}/results

5. Use Python Client:
   $ python example_experiment_client.py               # Basic example
   $ python example_experiment_client.py multi         # Multiple strategies
   $ python example_experiment_client.py high          # Priority handling
