# Créditos y licencias

`Earth-imagery.txt` conserva fuentes y atribución del proyecto. La Tierra usa mapas archivados NASA; las nubes de Solar System Scope están bajo CC BY 4.0 y se adaptan con opacidad/iluminación. La atribución no implica respaldo de estas organizaciones.

Las fuentes incluidas son Geist, Geist Mono y Manrope, con sus licencias SIL OFL originales en `fonts/`. Fuentes oficiales consultadas:

- https://raw.githubusercontent.com/google/fonts/main/ofl/geist/OFL.txt
- https://raw.githubusercontent.com/google/fonts/main/ofl/geistmono/OFL.txt
- https://raw.githubusercontent.com/google/fonts/main/ofl/manrope/OFL.txt

`dependencies.json` enumera las entradas resueltas del lockfile y sus metadatos de licencia. `packages/` conserva los archivos LICENSE/NOTICE presentes en la instalación local. El inventario no asigna una licencia nueva al código del proyecto ni reemplaza las condiciones de cada dependencia.

El logo v4 fue generado con la herramienta de imágenes; su prompt está en `brand/current/FlipFlop-HQ-Logo-Trading-notes.txt`. Los PNG son los archivos entregados, sin prometer exclusividad marcaria ni un original SVG que no existe.

Las referencias de usuario, capturas de Google/stock y vídeos se entregan como contexto de diseño. No se incorporaron automáticamente a la web pública ni se afirma tener una licencia de republicación de esos terceros. Las imágenes heredadas sin procedencia recuperada se identifican como históricas; comprobar derechos antes de usarlas en una publicación nueva.
