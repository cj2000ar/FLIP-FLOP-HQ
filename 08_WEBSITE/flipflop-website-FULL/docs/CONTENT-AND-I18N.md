# Contenido y traducciones

Idiomas: `es`, `en`, `pt`, `fr`, `it`, `de`. Cada diccionario tiene 374 entradas en la entrega base. Los componentes invocan `t(textoFuente)` a través del proveedor. `hq-website-language` es la clave de localStorage. El selector conserva una elección válida, maneja almacenamiento bloqueado y evita que una carga antigua sobrescriba una selección más reciente.

Al cambiar un texto visible, actualiza todas las claves/diccionarios y vuelve a ejecutar `npm test`. El español es la referencia; los números/códigos de instrumento y los términos técnicos no implican traducción de datos de mercado.
